# Lenses: session-start receipt (#61), hook safety (#67), conflicts (#64), trigger audit (#65)

Status: plan, 2026-11-04, no app code. A **Lens** is a read-only view computed from the saved scan JSON at request time, like `brief()`. Lenses add no provider call, no new scan pass (except one `stat` for CLAUDE.md in #61) and nothing to the public Snapshot. Tech: Python 3.13 + uv, FastAPI route in `server.py`, React + Tailwind tokens from `docs/design/DESIGN.md`, kind colours only via `--k-<kind>` CSS tokens (no new hex values).

## Shared rules (all four tickets)
- **One route**: `GET /api/lenses` (guarded by `local_only`), body `{"receipt": ..., "hooks": ..., "conflicts": ..., "triggers": ...}`; each ticket adds its own key. It loads the scan through the existing `read_items()` validator in `create_app`, so a bad scan is the same 404 "The saved scan could not be read".
- **Pure functions** `f(data: dict[str, Any]) -> ...` over the saved JSON, one new module per ticket. Disabled Items (`"disabled": true`) are left out of every lens (they do not load). Unknown is `None` and never counted as 0.
- **No description text in lens output** except the shared quoted phrase in a trigger conflict (#64). Hook command text never appears. Every ticket has a planted-secret test for this.
- **Tests**: through the HTTP API only (`TestClient(create_app(path, checklist=tmp_path / "c.md"), base_url="http://127.0.0.1:8765")`), invented scan dicts written to `tmp_path / "scan.json"`, plus `scan()` for #61. Never real `~/.claude`, transcripts or `.env`; `tests/conftest.py` already redirects caches. Add each new module to `only_mutate` in `pyproject.toml`; kill mutants with the boundary tests named below.
- **Frontend**: one component per ticket, rendered inside the Brief panel (below the existing cost and pairs groups), each a `<section aria-label=...>` with the Inspector's `h3` style (`text-xs font-medium tracking-[0.02em] text-text-3`). Rows are `Button variant="ghost"` that call Brief's existing `onItem(id)` to open the Inspector. No new library.
- **Files nobody here may touch**: `chat.py`, `answer.py`, `Chat.tsx` (Ask agents #53-#58), `StarMap.tsx`, `Atlas.tsx`, `Inspector.tsx` (shared), `snapshot.py`, `claude_code.py`, `hooks.py`, `make-demo.mjs`, `demo*.json` other than the new `demo-lenses.json`.
- **Shared files, additive edits only** (resolve rebase conflicts by keeping both sides): `server.py` (one dict key), `frontend/src/graph/lenses.ts` (one type), `Brief.tsx` (one import, one JSX line), `pyproject.toml` (one `only_mutate` entry), `docs/plan-tracker.md` (one section).
- **Merge order**: #61 first (creates the route, `lenses.ts`, `useLenses.ts`, the fixture), then #67, #64, #65 in any order; those three can be built in parallel on branches cut from #61's branch.
- Each ticket ends with all gates (AGENTS.md) + `npm run layout:check` + `npm run chat:check`, a tracker section, and screenshots in `docs/design/screenshots/lens-<n>-*.jpg` (demo data only).

## #61 Session-start receipt (size M)
**Goal**: one panel answering "what loads before my first prompt": hooks, CLAUDE.md, always-on descriptions, MCP tool schemas, each with tokens (or bytes, or unknown) and a total.
**Data**: `models.py` `Constellation.memory_bytes: int | None = None` (size of `config_dir / "CLAUDE.md"`, `None` when absent). `scan()` in `__init__.py`: `memory = Path(config_dir) / "CLAUDE.md"; memory_bytes = memory.stat().st_size if memory.is_file() else None` (stat only, content never read; comment `shortcut: user CLAUDE.md only, no @imports or project CLAUDE.md; upgrade when the scan reads projects (#43)`). No tokens: counting would send the file text.
**API** (`src/constellation/receipt.py`): `receipt(data) -> dict`:
`{"total_tokens": int | None, "uncounted_bytes": int, "unknown": int, "groups": [{"kind", "count", "tokens": int | None, "bytes": int, "unknown": int}], "rows": [{"id": str | None, "kind", "name", "tokens": int | None, "bytes": int | None}]}`.
Contributors: each non-disabled `skill`/`agent`/`command` (tokens = `costs[id].always_on`, unknown if missing/null); each non-disabled hook present in `hook_weights` (tokens if not null, else bytes, else unknown); CLAUDE.md as `{"id": None, "kind": "memory", "name": "CLAUDE.md", "bytes": memory_bytes}` when not null; each non-disabled `mcp_server`/`connector` as unknown (tool schemas need Expansion #9). Plugins themselves are not contributors. `total_tokens` = sum of known tokens, `None` if there are none. Groups in fixed order hook, memory, skill, agent, command, mcp_server, connector; empty groups dropped. Rows sorted by `(tokens is None, -(tokens or 0), -(bytes or 0), name, id)`, all rows returned.

## #67 Hook safety lens (size S, after #61)
**Goal**: every hook ranked by what it does to each prompt: event, what it runs, whether it can block, measured weight. No hook text in the output.
**API** (`src/constellation/hook_safety.py`): `hook_safety(data) -> list[dict]`, row `{"id", "name", "event", "matcher": str | None, "runs": "shell" | "mcp_tool", "phase": "session_start" | "before_prompt" | "each_tool_call" | "other", "can_block": bool, "bytes": int | None, "tokens": int | None}`. `event, matcher = name.split(":", 1)` (matcher `None` if no colon). Phase: `SessionStart` → session_start, `UserPromptSubmit` → before_prompt, `PreToolUse`/`PostToolUse`/`PermissionRequest` → each_tool_call, else other. `CAN_BLOCK = {"UserPromptSubmit", "PreToolUse", "PermissionRequest", "Stop", "SubagentStop"}` (exit code 2 or a block decision stops the step). `runs` = `"mcp_tool"` if a `triggers` Relation has this hook as source, else `"shell"` (comment `shortcut: an mcp_tool hook whose server was not found reads as shell; upgrade when the scan stores the handler type`). Weight from `hook_weights` (absent → both None). Sort `(PHASE_ORDER, not can_block, bytes is None, -(bytes or 0), name, id)` with order before_prompt, session_start, each_tool_call, other. Disabled hooks omitted.
**Files**: create `hook_safety.py`, `tests/test_hook_safety.py`, `frontend/src/components/HookSafety.tsx`; edit `server.py` (`"hooks": hook_safety(data)`), `lenses.ts`, `Brief.tsx`, `pyproject.toml`, tracker.
**TDD**: `test_hook_rows_split_event_and_matcher` (`PreToolUse:Bash` → event/matcher; `Stop` → matcher None; `PreToolUse:mcp__x:y` keeps `mcp__x:y`); `test_phase_and_block_table` (one row per listed event, plus an unknown event → other, False); `test_mcp_tool_hook_detected_by_relation`; `test_hook_rank_order` (before_prompt 10 bytes beats each_tool_call 9000 bytes; within a phase known bytes desc, unknown last, then name); `test_hook_weight_unknown_stays_none`; `test_hook_safety_never_returns_command` (description `curl -H "Authorization: sk-ant-api03-PLANTED"` absent from `/api/lenses` text); `test_disabled_hooks_omitted`.
**UI** (`HookSafety.tsx`): title "Hooks, by what they do to each prompt". Row: hook glyph, "{event}" + " · {matcher}" muted, second line "Runs a shell command" / "Calls an MCP tool", then "before every prompt" / "at session start" / "on every matching tool call" / "at {event}", then badge "Can block" (outlined, `--k-hook` border) when true; right side "{bytes} bytes" (+ " · {tokens} tokens" if known), or "unknown" for prompt-time hooks, nothing for others. Empty: "No hooks in this setup." Screenshots: demo-lenses desktop and phone; demo-250 (all rows "other" with names as events, checks long names wrap).

## #64 Conflict detector (size S, after #61)
**Goal**: deterministic collisions: two hooks on the same event and matcher, skills sharing a trigger phrase, MCP servers with the same name.
**API** (`src/constellation/conflicts.py`): `conflicts(data) -> list[dict]`, row `{"kind": "hook" | "trigger" | "mcp_name", "key": str, "item_ids": list[str], "reason": str}`; `item_ids` sorted; list sorted by `(kind order hook, mcp_name, trigger; key)`.
- hook: non-disabled hooks grouped by exact `name`, groups of 2+. Reason: "{n} hooks run on {event} ({matcher or 'every match'}). Claude Code runs them in parallel, so their order is not fixed."
- mcp_name: non-disabled `mcp_server` Items not inside a plugin (no `contains` Relation targets them) grouped by `name`, 2+. Reason: "{n} MCP servers are named {name}. Only one is used: local scope wins over project, project over user." (comment `shortcut: plugin servers are namespaced by Claude Code, so they are left out; tool-name collisions need Expansion (#9) mcp_tool Items`).
- trigger: quoted phrases in non-disabled skill descriptions, `re.findall(r'["“]([^"”]{3,80})["”]', d)`, lowercased and whitespace-collapsed, with 2+ words; a phrase in 2+ skills. Reason: "{n} skills claim the phrase \"{phrase}\", so either may answer it."
**Files**: create `conflicts.py`, `tests/test_conflicts.py`, `frontend/src/components/Conflicts.tsx`; edit `server.py` (`"conflicts"`), `lenses.ts`, `Brief.tsx`, `pyproject.toml`, tracker.
**TDD**: `test_two_hooks_same_event_and_matcher_conflict`; `test_same_event_different_matcher_no_conflict`; `test_single_hook_no_conflict`; `test_same_named_servers_conflict` (user/ and local/1/); `test_plugin_server_name_not_a_conflict`; `test_shared_quoted_phrase_conflict` (curly and straight quotes, case-insensitive); `test_one_word_or_short_phrase_ignored` ("pdf", "ab"); `test_phrase_in_one_skill_ignored`; `test_disabled_items_ignored`; `test_conflict_order_and_sorted_ids`.
**UI** (`Conflicts.tsx`): title "Conflicts". Row: reason text; below, the involved names as small ghost buttons opening each Item. Empty: "No conflicts found: no shared hook events, server names or trigger phrases." Screenshots: demo-lenses (three kinds) desktop/phone; demo-250 empty state.
**Privacy**: the phrase comes from descriptions already served by `/api/constellation`; nothing new leaves the machine. No Opus review needed.
**Acceptance**: [ ] demo-lenses gives exactly one conflict of each kind; [ ] demo-250 gives none; [ ] zero survivors.

## #65 Trigger audit (size S, after #61)
**Goal**: skills that never fire or fire greedily, from descriptions plus usage counts, no model.
**API** (`src/constellation/triggers.py`): `trigger_audit(data) -> dict`: `{"files": int, "rows": [{"id", "name", "count", "last_used": str | None, "flags": list[str]}]}`; `{"files": 0, "rows": []}` when `usage_window` is missing or has 0 files. Considers non-disabled skills with a `usage` entry. Flags: `"never"` (count 0); `"greedy"` (count >= `max(GREEDY_MIN, 4 * median)` with `GREEDY_MIN = 20`, median of positive skill counts via `statistics.median`); `"vague"` (description under 8 words, only reported together with `never`). Only flagged rows returned, sorted `(0 if greedy else 1, -count, name, id)`.
**Files**: create `triggers.py`, `tests/test_triggers.py`, `frontend/src/components/Triggers.tsx`; edit `server.py` (`"triggers"`), `lenses.ts`, `Brief.tsx`, `pyproject.toml`, tracker.
**TDD**: `test_never_fired_skill_flagged`; `test_no_window_returns_empty`; `test_greedy_boundary_min` (counts 1,1,2,20 → 20 flagged, 19 not); `test_greedy_boundary_median` (10,10,10,40 → 40 flagged, 39 not); `test_vague_only_with_never` (7 words + count 0 → `["never","vague"]`; 7 words + count 3 → not returned; 8 words + 0 → `["never"]`); `test_agents_and_hooks_not_audited`; `test_disabled_skill_ignored`; `test_audit_order`; `test_audit_has_no_descriptions`.
**UI** (`Triggers.tsx`): title "Trigger audit · {files} transcripts". Groups "Fires on almost everything" (greedy, "{count} uses") and "Never fired" ("never seen", plus muted "vague description" when flagged). Footer: "Counts come from saved transcripts; deleted transcripts are not counted." Empty: "No skill fires too often or never." Hidden when `files == 0` with "Not enough usage data: no transcripts were read." Screenshots: demo-lenses and demo-250 (many never-fired), desktop/phone.
**Privacy**: usage data is already local in the scan; output omits descriptions. No Opus review needed.
**Acceptance**: [ ] boundaries pass; [ ] coverage caveat visible; [ ] zero survivors.
